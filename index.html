💭 この活動について

なぜ、「母語の本」なのか

母語を失うことは、家族との会話を失い、自分のルーツから切り離され、「自分が好き」という感覚まで遠ざけてしまうこと。だからこそ、母語の本が必要です。

母語の物語に夢中になる、その時間のために。
🤝

母語と日本語は、対立しません

母語の力が育つことは、日本語の習得にもプラスに働きます。「どちらか」ではなく「どちらも」が、子どもの育ちを支えます。

💗

母語は、自己肯定感の土台

調査でも、母語・継承語のレベル（特に「話す」力）と、「今の自分が好きか」という自己肯定感との間に、明確な正の相関が見られました。

📖

本は、その入り口になります

母語で物語に触れられる一冊が、ことばと誇りを取り戻すきっかけになります。

出典：静岡県「令和5年度 外国にルーツを持つ子どもの実態・課題把握調査 報告書」（2024年3月／調査委託：静岡文化芸術大学）

📚 わたしたちがつくっているもの

OurDAISY（アワデイジー）

スマホやタブレットで無料で読める、多言語の電子図書館です。読むことが苦手な子も、耳と目で物語に入れる「マルチメディアDAISY図書」を、子どもたちの母語で制作しています。

🔊
文字を追いながら、音声で読み上げTTS（合成音声の読み上げ）で、文字と音がぴったり連動します。
📑
3つの読み方を1冊に母語／やさしい日本語／標準的な日本語。子どもの今の力に合わせて選べます。
🆓
無料で、いつでも、どこでも特別な技術がなくても低コストで運用できる仕組みづくりを進めています。
🌐
それぞれの母語で制作ラオス語・クメール語（カンボジア）、ネパール語・ミャンマー語…これからも対象言語を広げていきます。

🔍 くわしく知りたい方へ

お願いする作業の内容

気になる作業をタップすると、くわしい内容が開きます。詳しい手順書を用意しているので、たいていはそれを読めば解決できます。

🖨原稿づくり（絵本のスキャン → 文字の取り込み）ボランティア タイプA▶
紙の絵本から、専用OCRツール（EFAOurDaisyOCR＝文字を自動で読み取るアプリ）を使って、文字をWordファイルに取り込む作業です。完全オフラインで動く無料ツールで、詳しい手順書を用意しています。
📕 絵本の取り扱いについて 絵本は数が限られた大切な資産です。次のいずれかの方法で作業をお願いします。
① エファ東京事務所（市ヶ谷）でスキャンする
② 事務所まで絵本を取りに来て、借り受ける
③ 絵本を宅急便で受け取る
②③の場合は、2週間以内に宅急便でご返送ください（返送時の送料はご負担をお願いします）。
🖨 必要な機材 スキャナーをお持ちの方に限ります。スマートフォンでの撮影は、画質が安定しないため不可とさせていただきます。
💻 Windows PC🖨 スキャナー必須📂 ファイル操作の基本
✍️やさしい日本語の確認・微修正ボランティア タイプB▶
翻訳アプリが自動でつくった「やさしい日本語」版を読んで、小学1〜3年生に伝わるかを確認します。ぎこちない表現は、手順書のルールに沿って直します。このプロジェクトで最もやりがいのある作業のひとつです。
💻 Windows PC📝 Wordの基本🇯🇵 日本語が得意な方
🤖翻訳アプリの操作（3種類の日本語を生成）ボランティア タイプA▶
専用の翻訳アプリにWordファイルを読み込ませ、ボタンを押すだけで3種類の日本語バージョン（やさしい日本語・標準・母語のみ）が自動生成されます。操作はシンプルで、手順書で確認できます。
💻 Windows PC🌐 インターネット📂 ファイル操作の基本
📚電子図書アプリの操作（EPUBを生成）ボランティア タイプA▶
OurDAISYアプリにWordファイルを読み込ませると、音声つき電子図書（EPUB）が自動生成されます。タイトルなどの書誌情報を入力する場面がありますが、項目は決まっていて迷いません。
💻 Windows PC📂 ファイル操作の基本
👂読み上げ音声の確認ボランティア タイプC▶
完成した電子図書の音声を聴いて、読み間違いがないか確認します。「は」を「わ」と読むなど、コンピュータが苦手な助詞の読み方を中心にチェック。気になる箇所はフォームに記入するだけです。
💻 PC または スマホ🔊 音声が聴ける環境
