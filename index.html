💭 この活動について

なぜ、「母語の本」なのか

母語を失うことは、家族との会話を失い、自分のルーツから切り離され、「自分が好き」という感覚まで遠ざけてしまうこと。だからこそ、母語の本が必要です。

母語の物語に夢中になる、その時間のために。
🤝

母語と日本語は、対立しません

母語で育った「考える力」や読み書きの力は、日本語にも引き継がれます（言語相互依存仮説）。「どちらか」ではなく「どちらも」が、子どもの育ちを支えます。

💗

母語は、自己肯定感の土台

静岡県の中学生2,080人への調査では、母語・継承語の力が高い子ほど、自分自身への満足度や自己肯定感も高い傾向（正の相関）が見られました。特に「話す」力との関係が強く出ています。

📖

本は、その入り口になります

母語で物語に触れられる一冊が、ことばと誇りを取り戻すきっかけになります。

出典：静岡県「令和5年度 外国にルーツを持つ子どもの実態・課題把握調査 報告書」（2024年3月／静岡文化芸術大学に委託、県内公立中学校6校の1〜3年生2,080人が回答）。言語相互依存仮説はJ.カミンズによる考え方。
冒頭の人数：文部科学省「日本語指導が必要な児童生徒の受入状況等に関する調査（令和7年度）」（2025年5月1日時点、2026年5月公表。外国籍73,313人・日本国籍11,446人、前回〔2023年〕から15,636人増）

📚 わたしたちがつくっているもの

OurDAISY（アワデイジー）

スマホやタブレットで無料で読める、多言語の電子図書館です。読むことが苦手な子も、耳と目で物語に入れる「マルチメディアDAISY図書」を、子どもたちの母語で制作しています。

🔊
文字を追いながら、音声で読み上げTTS（合成音声の読み上げ）で、文字と音がぴったり連動します。
📑
3つの版から選べる母語／母語＋やさしい日本語／母語＋標準日本語。子どもの今の力に合わせて選べます。
🆓
無料で、いつでも、どこでも特別な技術がなくても低コストで運用できる仕組みづくりを進めています。
🌐
それぞれの母語で制作ポルトガル語・ネパール語・ラオス語・ミャンマー語など、現在12言語に対応しています（2026年10月時点）。これからも対象言語を広げていきます。

制作・アプリ担当

日本語校正担当

こんな方に：日本語の読み書きが得意な方。教育関係者・文章好きの方歓迎。
C
🎧
ボランティア タイプC

音声確認担当

機械音声（TTS）が正しく読めているかを、リーダーアプリ（電子図書を再生する無料アプリ）で再生して確認。アプリを入れたパソコンかスマホがあれば参加できます。

こんな方に：音や朗読を聴くのが好きな方。語学好き・外国語経験者歓迎。
🧩 「1冊まるごと」ではなく「1タスクずつ」。
作業は小さなタスク（仕事）単位に分かれています。担当したいタスクを1つ予約 → 完了 → また次へ。自分のペースで、無理なく続けられます。手があいているタスクなら、別のタイプの作業に挑戦することもできます。
📚 あなたの名前が、本に残ります。
担当した作業ごとに、電子図書と図書館のページに「つくった人」として名前が載ります。どのタイプでも同じです。
翻訳 / Translation：YAMADA Hanako
名前はローマ字で、姓・名の順に載ります。載せるかどうかは、登録のときに自分で選べます（あとから変えられます）。

🖨原稿づくり（絵本のスキャン → 文字の取り込み）ボランティア タイプAときどき▶
💡 この作業は、ときどき発生します。ほとんどの絵本は、現地の言語ですでにWord原稿になった状態で届くため、作業は「翻訳アプリの操作」から始まります。紙の絵本しかないときだけ、この作業をお願いしています。
紙の絵本から、専用OCRツール（EFAOurDaisyOCR＝文字を自動で読み取るアプリ）を使って、文字をWordファイルに取り込む作業です。完全オフラインで動く無料ツールで、詳しい手順書を用意しています。
📕 絵本の取り扱いについて 絵本は数が限られた大切な資産です。次のいずれかの方法で作業をお願いします。
① エファ東京事務所（市ヶ谷）でスキャンする
② 事務所まで絵本を取りに来て、借り受ける
③ 絵本を宅急便で受け取る
②③の場合は、2週間以内に宅急便でご返送ください（返送時の送料はご負担をお願いします）。
🖨 必要な機材 スキャナーをお持ちの方に限ります。スマートフォンでの撮影は、画質が安定しないため不可とさせていただきます。
💻 Windows PC🖨 スキャナー必須📂 ファイル操作の基本
🤖翻訳アプリの操作（3種類の版を生成）ボランティア タイプA▶
専用の翻訳アプリにWordファイルを読み込ませ、ボタンを押すだけで3種類の版（母語・母語＋やさしい日本語・母語＋標準日本語）のWordファイルが自動生成されます。操作はシンプルで、手順書で確認できます。

💻 Windows PC📝 Wordの基本🇯🇵 日本語が得意な方
📚電子図書アプリの操作（EPUBを生成）ボランティア タイプA▶
OurDAISYアプリにWordファイルを読み込ませると、音声つき電子図書（EPUB）が自動生成されます。タイトルなどの書誌情報を入力する場面がありますが、項目は決まっていて迷いません。
💻 Windows PC🌐 インターネット⚙️ アプリのインストール（Pythonなど）📂 ファイル操作の基本
👂読み上げ音声の確認ボランティア タイプCボランティア タイプA▶
完成した電子図書の音声を聴いて、読み間違いがないか確認します。「は」を「わ」と読むなど、コンピュータが苦手な助詞の読み方を中心にチェック。気になる箇所は、記録用のレポートフォーム（Wordファイル）に書き込むだけです。
🎧 リーダーアプリ（電子図書を再生する無料アプリ）が必要です
音声は、完成した電子図書（EPUB）をリーダーアプリで再生して聴きます。作業を始める前に、お使いの端末に合ったアプリを1つ入れておいてください。

・iPhone／iPad：EasyReader

できあがるのは、こんな電子図書

文字に合わせて音声が流れ、読んでいる場所がハイライトされます。母語と日本語、両方で楽しめる「音声つきの本」です。

インドネシア語 × やさしい日本語のバイリンガル電子図書

読み上げに合わせて、読んでいるところが光ります。母語と、ふりがな付きのやさしい日本語が1ページに並び、絵の説明も読み上げます。
